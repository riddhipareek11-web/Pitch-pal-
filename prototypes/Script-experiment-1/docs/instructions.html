PROTOTYPE: SCRIPT-EXPERIMENT-1

AI Script Generator

Follow these steps to run the backend and frontend on your macOS device.

🛠️ Prerequisites for macOS

  • Node.js installed (v18 or higher recommended). Check via: 
    node -v
  • A Google Gemini API Key. Obtain one for free from Google AI Studio.

1 Setup & Start Backend

The backend requires setting up environment variables and starting the Node.js server.

  1. Open a Terminal window and navigate to the backend directory: 
    cd prototypes/Script-experiment-1/backend
  2. Install Node dependencies: 
    npm install
  3. Create your local configuration file and add your Google Gemini API key: 
    echo "GEMINI_API_KEY=YOUR_ACTUAL_API_KEY_HERE" > .env
    ⚠️ Important Security Tip: Do not commit the modified .env file to git. It is ignored by default in the project configuration.
  4. Start the backend server: 
    npm start
    The terminal will output: "Server is running on port 5001". Keep this terminal tab running.

2 Setup & Start Frontend

Run the React frontend via Vite in a new Terminal window or tab.

  1. Open a new Terminal tab (press Cmd + T in Terminal) and navigate to the frontend directory: 
    cd prototypes/Script-experiment-1/frontend
  2. Install Node dependencies: 
    npm install
  3. Start the frontend development server: 
    npm run dev
  4. Open the React application in your browser: 
    open http://localhost:5173
    Vite normally serves the UI on port 5173. Verify the port in the terminal output if it defaults to a different port.
