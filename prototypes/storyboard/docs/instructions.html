PROTOTYPE: STORYBOARD

AI Storyboard App

Follow these steps to run the browser-based storyboard generator on your macOS device.

💡 Why Run a Local Server?

When opening the storyboard index.html directly from your hard drive (using a file:/// URL), modern web browsers block API requests to the Hugging Face Inference API due to CORS (Cross-Origin Resource Sharing) security rules, throwing a "Failed to Fetch" error.

✅ The Solution: Running a simple Python web server serves the app through http://localhost:8000. This is considered a secure origin, bypassing the CORS block completely.

1 Start the Local Server

Since everyone on the team is on a MacBook, Python 3 is available natively via Terminal.

  1. Open your Terminal application.
  2. Navigate to the storyboard prototype directory: 
    cd prototypes/storyboard
  3. Spin up Python's built-in lightweight HTTP server: 
    python3 -m http.server 8000
    The terminal will output: "Serving HTTP on :: port 8000...". Keep this terminal window open.

2 Open and Generate

  1. Open the application in your browser: 
    open http://localhost:8000
  2. In the app UI:
    • Enter your **Google Gemini API Key** (for text generation).
    • Enter your **Hugging Face Access Token** (for generating the sketches).
  3. Click Load Sample Data to pre-fill the form, then click Generate Storyboard!
