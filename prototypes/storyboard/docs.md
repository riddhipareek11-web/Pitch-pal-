# AI Storyboard App Documentation

## Project Overview
This project is a single-file, zero-dependency web application designed to help non-technical users and UGC creators instantly generate professional storyboards. 

The app takes in a Content Goal, Target Audience, Brief, and Script, and uses Artificial Intelligence to break the script down into a 4-frame storyboard complete with Director Notes, Actions, Voiceover text, and automatically generated storyboard sketches.

## Architecture & Tech Stack
- **Frontend:** Pure HTML, CSS, and Vanilla JavaScript (`index.html`). No backend server, frameworks, or package managers required.
- **Text Generation / Reasoning API:** Google AI Studio (Gemini API)
  - **Model:** `gemini-3.6-flash`
  - **Purpose:** Acts as the "Director". It parses the user's script, structures the 4 frames, writes the dialogue/actions, and writes highly specific image prompts for the artist model.
  - **Data Structure:** The AI is strictly prompted to output a raw JSON object to prevent parsing errors and guarantee exactly 4 frames are generated.
- **Image Generation API:** Hugging Face Free Inference API
  - **Model:** `stabilityai/stable-diffusion-xl-base-1.0`
  - **Purpose:** Acts as the "Artist". It takes the image prompts generated by Gemini and draws them into the storyboard boxes.
  - **Style Enforcement:** The prompt is secretly prepended with strict instructions (`"Black and white vector line art, clean manga comic style drawing, no shading, pure white background."`) to force the AI to draw flat line art rather than photorealistic images.

## Development History & Troubleshooting Log

During development, we encountered and solved several critical challenges regarding AI APIs:

### 1. Image Style & Photorealism Stubbornness
* **Issue:** Free image models (like Pollinations.ai) stubbornly defaulted to drawing 3D photorealistic images (e.g., a real photograph of a blue pen on a piece of paper) instead of the requested stick-figure sketches.
* **Fix:** We completely rewrote the prompt constraints, switching to a "Coloring book / Manga line art" style rule, which the AI understands much better than "doodle." We hardcoded these style prefixes directly into the API request to override any photorealistic tendencies.

### 2. Missing Frames / Parsing Errors
* **Issue:** Initially, Gemini was returning plain text separated by `---FRAME---`. Sometimes, the AI would hallucinate the formatting or forget the separator, causing the JavaScript regex to crash and only render 1 frame.
* **Fix:** We overhauled the Gemini prompt to demand a strict `JSON` response structure. By parsing standard JSON, we guarantee that all 4 frames are loaded perfectly every single time without regex bugs.

### 3. Google AI Studio Native Image Quotas
* **Issue:** We attempted to switch the image generation to Google's native multimodal model (`gemini-2.5-flash-image`) to consolidate everything under one API key. However, Google enforces a strict `limit: 0` quota on free-tier accounts for image generation in certain regions/ages to prevent spam.
* **Fix:** To keep the app 100% free without requiring the user to attach a credit card to Google Cloud Billing, we pivoted to the **Hugging Face Free Inference API**. We added a second input box for a Hugging Face Access Token, allowing the user to generate high-quality images completely for free.

### 4. Hugging Face CORS Blocks (Failed to fetch)
* **Issue:** When running the app directly from the hard drive (`file:///index.html`), the browser blocked the Hugging Face API requests due to CORS (Cross-Origin Resource Sharing) security rules, throwing a "Failed to fetch" error.
* **Fix:** We spun up a background Python web server (`python3 -m http.server 8000`) and opened the app via `http://localhost:8000`. By serving the file through localhost instead of a raw file path, the browser considers it a secure origin and allows the Hugging Face API requests to go through.

## How to Run the App
1. Open `index.html` in any modern web browser (e.g., Google Chrome).
2. Enter your **Google Gemini API Key** (for text generation).
3. Enter your **Hugging Face Access Token** (for image generation).
4. Click **Load Sample Data** or fill out the script manually.
5. Click **Generate Storyboard** and wait for the AI to process and load the images.
